This is a Web Solution that presents a financial advisor to Motswana nation wide.
It is not limited to who it is intended for, and if one may so chose to use the source code by cloning or forking the repository, they are agreeing to the terms this solution
was developed by and is maintained by: https://OPenlink/from/terrence/. 
The solution works to read the transactions and goals set by the user's activity and intention submissions, and feed a prompt to an Ai model.
The Ai model will then give suggestions on who best to achieve the goals and preferences it set in the beginning.
This solution also exposes a user of the application to a global portfolio that they can opt-in to.
This portfolio will be managed by the banks that opt-in to providing their services to maintaining the portfolio.
